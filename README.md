# GitHub User Finder

A responsive **GitHub User Finder** application built with React that allows users to search for GitHub users by their username or GitHub ID.

## Live Demo

[View GitHub User Finder](https://github-userfinderapp.netlify.app/)

## Built With

* React
* JavaScript
* Tailwind CSS
* GitHub API
* Create React App

## Features

* Search GitHub users by username
* Search users by GitHub ID
* Fetches user data from the GitHub API
* Responsive design
* Clean and simple user interface
* Interactive UI elements

## What I Learned

This project helped me practice:

* Using APIs with `fetch()`
* Handling user input and events
* Filtering API data
* Building responsive interfaces with Tailwind CSS
* Deploying a React application with Netlify

## Getting Started

Clone the repository:

```bash
git clone https://github.com/tehamkhan2007-design/github-user-finder.git
```

Navigate to the project:

```bash
cd github-user-finder
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```
